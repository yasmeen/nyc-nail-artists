# Redesign directions (drafts)

Three static drafts for choosing a direction before `index.html` changes. Open them from the dev server: `npm run dev`, then `/design-demos/a-lookbook.html` (they load `../photos/` and `data.js`).

`data.js` is generated by `build_data.py` from `test.csv`, `geo.json`, `booking.json` and `photos/manifest.json`. Walk times use the app's street-grid estimate from Union Square at about 3 mph.

| Draft | Idea | Leads with |
|---|---|---|
| `a-lookbook.html` | Find the set first, then the place. Saved photos are the index; places without photos become a plain list instead of grey boxes. | Nail photos and "looks" (tortoiseshell, chrome, cat eye…) |
| `b-shortlist.html` | Compare like flights. Each place is a row with its price drawn against your budget, walk time and next opening, grouped into "fits", "close (misses one thing)" and "can't compare yet". | Price, walk and openings side by side |
| `c-around-you.html` | Start from where you are. Price pins on a drawn Manhattan grid, with walk-time rings that follow the street grid (so they're diamonds), and a list sorted by walk time. | Location and walking distance |

Mocked or placeholder in these drafts:
- Opening times are mock data (labelled on each page).
- Instagram embeds aren't used; only the saved photos in `photos/` appear.
- Map C is a hand-drawn SVG of the street grid, not OpenStreetMap tiles.
- Artonus Nailsroom, Emi Aoki and The Shade NYC have saved photos but aren't in `test.csv`, so they show no prices.
- Light mode only so far.
